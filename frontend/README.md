Frontend notes

Choice: Next.js (React) or Streamlit for fast demo.

Essential features for hackathon UI:
- File upload
- Progress stream (list of MCP tool calls + status)
- Clause viewer (highlighted text + extracted entities)
- Risk dashboard (severity counts)
- Download JSON + summary PDF

For a quick demo, Streamlit is fastest; for a polished look, Next.js + React with WebSocket streaming for live MCP logs.
