    -F 'file=@demo/sample.mp4' | jq '.events | length'

View Audit Trail
  curl http://localhost:8001/audits | jq '.audits | length'

Async Upload Workflow
  # Step 1: Upload
  JOB=$(curl -s -X POST http://localhost:8000/upload_async \
    -F 'file=@demo/sample.mp4' | jq -r '.job_id')
  
  # Step 2: Poll
  curl http://localhost:8000/status/$JOB
  
  # Step 3: Get results
  curl http://localhost:8000/result/$JOB | jq '.result.events | length'

🔧 OPTIONAL: Real YOLOv8 Detection
─────────────────────────────────────────────────────────────────────────────

By default: Deterministic demo detector (always produces same 6 violations)

To enable real YOLO:
  1. Download yolov8n.onnx from Ultralytics
  2. Create models/ folder: mkdir models
  3. Place: yolov8n.onnx → models/yolov8n.onnx
  4. Restart MCP: docker-compose restart mcp-server

System will auto-detect and use real model (graceful fallback if absent).


🛠️ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Port 8000/8001/8501 in use?
  pkill -f 'uvicorn\|streamlit'
  docker-compose down
  docker-compose up --build

Docker won't build?
  docker system prune
  docker-compose up --build --no-cache

Services won't start?
  docker-compose logs        (see all logs)
  docker-compose logs mcp    (just MCP)
  docker-compose logs backend (just backend)

PDF won't download?
  curl http://localhost:8001/audits | jq '.audits[] | select(.tool=="generate_report")'
  (Check the out_path in the log)
